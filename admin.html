How to update

  1. Change price and stock (bunches available today). Leave stock empty for no limit. Stock 0 or "Available" unticked = out of stock.
  2. Tap Download prices.json.
  3. Put that file in your website folder (replace the old prices.json) and upload the folder again. The website shows the new prices and stock straight away.
  4. Copy the WhatsApp messages below, which are built from the same list, and paste them into WhatsApp.

Names, prices and stock in English and Kannada. Paste it as a Quick reply (type / in a chat), a Status, or send it to customers. Update it each day.

WhatsApp message 2: auto-reply when a customer sends "Hi"

Welcome + today's soppu and prices, in Kannada and English. Paste it in WhatsApp Business → Business tools → Greeting message. It is then sent automatically to anyone who messages you. Come back here each morning, copy it again and paste the new one, so the list stays up to date.

WhatsApp message 3: greeting with link only (set once)

Use this if message 2 is too long for the greeting box. It has no prices, only your website link, and the website always shows the latest prices and stock.
